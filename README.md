# ArJai · ДоСи — сайт

Сайт музыкальной студии ArJai (Алматы, с 2014 года) и авторской системы обучения «ДоСи» Сауле Джайлауовой.
Чистый HTML/CSS/JS, без сборки и сторонних библиотек. Публикуется через GitHub Pages из ветки `main`:
https://quickorder65-eng.github.io/Arjai/

## Как собираются страницы

Шапка, подвал, блок заявки, анкета и `<head>` (SEO, schema.org) общие для всех страниц и лежат в `tools/make_pages.py`.
Содержимое каждой страницы — в `tools/pages/<страница>.html`.

1. Правите `tools/pages/…` или общие части в `tools/make_pages.py`.
2. `python3 tools/make_pages.py` — собирает русские страницы в корне (FAQ для поисковиков строится сам из вопросов на странице).
3. `python3 tools/build_kk.py check` — покажет новые тексты без перевода; переводы добавить в `tools/kk.json`.
4. `python3 tools/build_kk.py build` — собирает казахские страницы в `kk/`.

Готовые HTML в корне и в `kk/` руками не правятся — они перезаписываются при сборке.

## Анкета

Любая кнопка с `data-quiz` открывает полноэкранную анкету. Маршруты: `kids`, `adult`, `stage`, `workshop`, `recording` (ArJai) и `staff`, `teacher`, `owner` (ДоСи), `other` — «Другое». `data-quiz="arjai"` / `"dosi"` — выбор только внутри группы, `data-quiz="vocal"` (и другие направления) — выбор маршрута с уже выбранным направлением. Ссылка `index.html#quiz-kids` (и т. п.) открывает анкету сразу.

В каждом вопросе есть вариант «Другое» с полем для своего ответа. В конце — рекомендация, ответы уходят в WhatsApp, затем экран «Спасибо» с тем, что будет дальше. За анкету обещана бесплатная диагностика. Тексты на двух языках — в `assets/script.js` (объект `T`, блоки `ru` / `kk`, маршруты — `ROUTES`).

При первом входе посетитель выбирает язык, выбор запоминается; в шапке есть переключатель ҚАЗ / РУС. Браузерный автоперевод на сайте отключён (`notranslate`), чтобы казахская версия не «прыгала» на русский.

## Как работают заявки

Бэкенда нет. Все кнопки («Записаться на занятие», «Пройти диагностику», «Получить программу ДоСи», «Консультация для школы», «Задать вопрос») и форма в контактах открывают WhatsApp с уже готовым текстом. Анкета прикладывает ответы к сообщению.

Номер WhatsApp и тексты сообщений меняются в одном месте — в начале `assets/script.js` (`WA_PHONE` и `MESSAGES`).

## Черновые пометки

Обычный вид сайта — чистый, без пометок. Чтобы показать заказчику, что ещё нужно уточнить, откройте сайт с `?draft=1` в адресе — появятся жёлтые пометки «Уточнить: …».

## Технически

- Шрифт Onest (SIL Open Font License) лежат в `assets/fonts` — сайт не зависит от Google Fonts.
- SEO: title/description на каждой странице, Open Graph и Twitter-карточка (`assets/og-image.png`), favicon, schema.org `EducationalOrganization` на главной и `Course` на странице курса, `sitemap.xml`, `robots.txt`.
- Без scroll-анимаций, счётчиков и пульсирующих элементов — по просьбе заказчика.

## Продвижение в поиске (SEO)

Сделано на сайте: заголовки и описания страниц под запросы «уроки вокала Алматы», «уроки фортепиано Алматы», «курс для преподавателей музыки»; разметка schema.org (организация, Сауле Джайлауова с наградой, цены, FAQ, хлебные крошки); карта сайта с изображениями; альтернативные названия в разметке — «Творческая мастерская Архаровых», «ДоСи».

Первое место сайт сам по себе не гарантирует. Что нужно сделать вне сайта (по важности):
1. Свой домен (например, arjai.kz) — поиск лучше доверяет собственному домену, чем адресу github.io. После покупки заменить адрес в canonical, Open Graph, schema, sitemap.xml, robots.txt.
2. Google Search Console и Яндекс Вебмастер: подтвердить сайт (прислать код — вставлю в `<head>`), отправить `sitemap.xml`.
3. Карточки организации: Google Business Profile, 2GIS, Яндекс Бизнес — с адресом, телефоном, фото, ссылкой на сайт. Для запросов «рядом» это важнее всего.
4. Отзывы учеников в Google и 2GIS.
5. Ссылка на сайт в шапке Instagram, описании YouTube-канала и Telegram.
