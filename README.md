# ArJai · ДоСи — сайт

Сайт музыкальной студии ArJai (Алматы, с 2014 года) и авторской системы обучения «ДоСи» Сауле Джайлауовой.
Чистый HTML/CSS/JS, без сборки и сторонних библиотек. Публикуется через GitHub Pages из ветки `main`:
https://quickorder65-eng.github.io/Arjai/

## Страницы

| Файл | Что это |
|---|---|
| `index.html` | Главная: два пути с первого экрана (ArJai — ученикам и родителям, ДоСи — педагогам и школам), занятия и цены, мастерская, студия звукозаписи, методика от ДО до СИ, программа ДоСи, блок о Сауле, результаты, отзывы, анкета на 5 шагов, FAQ, контакты |
| `repetitor.html` | Курс «Успешный репетитор ДоСи» (Разбор → Система → Методика → Бизнес-установка) |
| `shkolam.html` | B2B: внедрение ДоСи в музыкальные школы и студии |
| `404.html` | Страница «не найдено» |

## Как работают заявки

Бэкенда нет. Все кнопки («Записаться на занятие», «Пройти диагностику», «Получить программу ДоСи», «Консультация для школы», «Задать вопрос») и форма в контактах открывают WhatsApp с уже готовым текстом. Анкета прикладывает ответы к сообщению.

Номер WhatsApp и тексты сообщений меняются в одном месте — в начале `assets/script.js` (`WA_PHONE` и `MESSAGES`).

## Черновые пометки

Пока данные не согласованы, на сайте видны жёлтые пометки «Уточнить: …» и полоса «Черновик» сверху.
- Посмотреть сайт без пометок: добавить к адресу `?draft=0`.
- Убрать пометки при запуске: удалить `class="draft"` у тега `<html>` в `index.html`, `repetitor.html`, `shkolam.html`.

## Технически

- Шрифты Golos Text и Source Serif 4 (SIL Open Font License) лежат в `assets/fonts` — сайт не зависит от Google Fonts.
- SEO: title/description на каждой странице, Open Graph и Twitter-карточка (`assets/og-image.png`), favicon, schema.org `EducationalOrganization` на главной и `Course` на странице курса, `sitemap.xml`, `robots.txt`.
- Без scroll-анимаций, счётчиков и пульсирующих элементов — по просьбе заказчика.
